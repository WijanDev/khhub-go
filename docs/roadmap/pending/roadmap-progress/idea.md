## Summary

Each `summary.md` section shows how many ideas it holds and what share that is of the active total. A later slice splits **planned** out of pending and names the app version that slice is meant for.

## Out of scope

- A generated dashboard or CI job that rewrites the tables.
- Inventing version numbers. Target version comes from the repo `VERSION` file (or the next agreed bump), same rule as implemented rows.
- Counting dropped ideas in the percentage denominator.
