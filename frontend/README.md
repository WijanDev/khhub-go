# Frontend

Vite + React 19 SPA for khhub. User-facing copy is Spanish.

From this directory: `npm install && npm run dev`. Set `VITE_API_URL=http://127.0.0.1:8080` (see the repo `.env.example`). The browser talks to the API directly.

Product setup, deploy, and agent rules live in the repository root (`README.md`, `AGENTS.md`, `ROADMAP.md`).
